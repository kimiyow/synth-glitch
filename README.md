# Synth Glitch

Aplicación móvil hecha con Expo y React Native para capturar fotos y manipularlas como un instrumento visual mediante gestos táctiles y efectos glitch.

## Estado del proyecto

Las fases 0 a 4 están cerradas. La fase 5, guardado e historial, está en curso. El editor permite controlar con un gesto de un dedo aberración cromática, scanlines CRT y datamosh; el plan contempla seis efectos en total.

## Desarrollo

Instala las dependencias y arranca Expo:

```bash
npm install
npm run start
```

Para revisar el código:

```bash
npm run lint
npx tsc --noEmit
```
